
# 🎮 Super Jump Adventure

A fun, browser-based jumping game built using HTML, CSS, and JavaScript.

Jump over obstacles, collect coins, and try to achieve the highest score!

## 🌐 Live Demo

👉 https://aratik9.github.io/wordgame/

## ✨ Features

- 🕹️ Simple and fun gameplay
- 🦘 Jump over obstacles
- 🪙 Collect coins to earn points
- 📈 Increasing game difficulty
- 📱 Mobile-friendly controls
- 💻 Keyboard support
- 🔄 Restart option
- 🎨 Colorful graphics
- 🚀 No installation required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 🎮 How to Play

1. Open the game in your browser.
2. Press the **JUMP** button to jump over obstacles.
3. Collect coins to increase your score.
4. Avoid obstacles to keep playing.
5. Press **RESTART** to play again.

### Controls

| Action | Control |
|---|---|
| Jump | Space / Arrow Up |
| Mobile jump | JUMP button |
| Restart | RESTART button |

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/aratik9/wordgame.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!
